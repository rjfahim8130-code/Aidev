# AI Dev Studio (Android APK)

মোবাইলের জন্য তৈরি **AI কোডিং অ্যাসিস্ট্যান্ট**।  
DeepSeek / Grok / OpenAI-compatible API + GitHub-এ সরাসরি কোড পুশ করে।

সব ডেটা শুধু আপনার ফোনের ভিতরে থাকে। কোনো সার্ভার নেই, কোনো ব্যবহারের লিমিট নেই।

---

## দ্রুত APK বানানোর উপায় (GitHub Actions)

### ধাপ ১: রিপোজিটরি তৈরি
1. এই ফোল্ডারের সব ফাইল আপনার GitHub-এ নতুন রিপোজিটরিতে আপলোড করুন।
2. রিপোর নাম যা খুশি রাখতে পারেন (যেমন: `ai-dev-studio`).

### ধাপ ২: Actions চালু করুন
1. রিপোজিটরিতে গিয়ে উপরের মেনু থেকে **Actions** ট্যাবে যান।
2. যদি জিজ্ঞেস করে তাহলে **I understand...** বা Enable workflows ক্লিক করুন।
3. বাম পাশে **Build Android APK** ওয়ার্কফ্লো দেখতে পাবেন।
4. **Run workflow** বাটনে ক্লিক করে চালু করুন (অথবা `main` ব্রাঞ্চে কিছু পুশ করলে অটো চলবে)।

### ধাপ ৩: APK ডাউনলোড
1. ওয়ার্কফ্লো শেষ হলে সবুজ টিক চিহ্ন দেখাবে।
2. সেই রানের ভিতরে গিয়ে নিচে **Artifacts** সেকশনে **AI-Dev-Studio-APK** দেখতে পাবেন।
3. ডাউনলোড করুন → আনজিপ করুন → `app-debug.apk` ফাইল পাবেন।

### ধাপ ৪: ফোনে ইনস্টল
1. ফোনে **Unknown sources / Install unknown apps** অন করুন।
2. APK ফাইল ওপেন করে ইনস্টল করুন।
3. অ্যাপ খুলে ⚙️ সেটিংস থেকে API Key ও GitHub Token দিন।

---

## GitHub Token কিভাবে পাবেন? (ফ্রি অ্যাকাউন্টেই)

1. GitHub → প্রোফাইল → **Settings**
2. নিচে **Developer settings**
3. **Personal access tokens → Tokens (classic)**
4. **Generate new token (classic)**
5. **`repo`** স্কোপ টিক দিন
6. Generate করে টোকেন কপি করে রাখুন

অ্যাপে সেটিংসে বসিয়ে **রিপোজিটরি লোড করুন** চাপুন।

## ফিচার

- একাধিক আলাদা কনভারসেশন (মিশে না)
- প্রতি চ্যাটে আলাদা GitHub রিপো সেট
- AI-এর দেওয়া ফাইল এক ক্লিকে GitHub-এ Push
- পুরো চ্যাট `.md` ডাউনলোড
- একক মেসেজ `.txt` ডাউনলোড
- ফাইলগুলো `.zip` ডাউনলোড
- সম্পূর্ণ অফলাইন চ্যাট হিস্ট্রি

## নোট

- এটি **Debug APK**। ব্যক্তিগত ব্যবহারের জন্য পুরোপুরি যথেষ্ট এবং কোনো লিমিট নেই।
- Play Store-এ আপলোড করতে চাইলে Signed Release APK লাগবে (আলাদা keystore প্রয়োজন)।
- প্রথমবার ওয়ার্কফ্লো চলতে ৩–৬ মিনিট সময় লাগতে পারে।

কোনো সমস্যা হলে Actions ট্যাবের লগ দেখে বলুন।
